# 화면 브리프 폴더

화면 하나마다 브리프 파일 하나를 여기에 둬요. 이름은 경로를 따라 `<page>.md`로 써요(예: `/training` → `training.md`, `/hiring/:id` → `position.md`).

- 틀은 `../SCREEN_BRIEF_TEMPLATE.md` 1장이에요. 두 앱을 만들 때 **실제로 쓴 브리프**는 `_examples/`에 있어요(얼마나 구체적으로 써야 하는지 보는 용도. 구성 규칙(PLAYBOOK 5.0) 전에 쓴 거라 레퍼런스 배치·KPI 띠를 정한 방식은 따라 하지 않아요. 숫자·경로도 그때 기준이라 지금 seed와 AGENTS.md가 우선이에요). 2장의 채운 예는 형식 견본이라 숫자를 그대로 쓰지 않아요. 숫자·사람은 seed(hr `src/data/seed.ts`, 업무사이트 `src/data/{tr,crata}.ts`)에서 다시 계산해요.
- 사람이 쓰든 Codex가 초안을 쓰든 같은 자리에 둬요. 사람이 대화 중이면 Codex는 초안을 보여 주고 확인을 기다려요. 무인 실행이면 여기에 쓰고 바로 진행하고, 확인받지 못한 판단은 결과 보고의 '승인 전 가정'에 적어요.
- 과제가 다른 위치를 정하면 그 위치가 우선이에요.
- 브리프에는 근거 문서 경로를 적어요. 저장소에 그 문서가 없으면 "없음, 확인 필요"라고 적어요.
