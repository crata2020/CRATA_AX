# 화면 완료 체크리스트

화면 하나를 "끝났다"고 하기 전에 위에서부터 확인해요. 못 지킨 항목은 이유를 결과 보고에 적어요. 괄호 안은 리뷰에서 실제로 걸렸던 사례예요.

## 1. 기계 검사
- [ ] `npm run typecheck` 0 오류, `npm test`(hr. 새 `src/lib/<page>.test.ts`도 여기서 돌아요) 통과, `npm run build` 성공
- [ ] `ui-check --fold --a11y` 내 경로 × d·t·m 0 problems: 넘침 없음, h1 = 1, 보이는 `.btn--dark` ≤ 1, 콘솔 오류 0, 라벨 없는 입력 0, 이름 없는 버튼·링크 0
- [ ] 404(`/nope`)와 없는 id(`/hiring/zzz`)에서도 h1 1개, 오류 0
- [ ] 셸(`Shell.tsx`, `App.tsx`)을 바꿨으면 전 경로(`@routes.hr.json` 등)도 0 problems
- [ ] `--flow`로 주 동작을 눌러 본 캡처가 있고, 그 shot들도 0 problems예요. `WARN TOAST_COVERS`는 공통 파일 문제로 보고해요

## 2. 모양(fold 캡처를 레퍼런스와 나란히)
- [ ] 흰 틀 + #f6f6f8 캔버스 + 흰 카드(1px `--line`, 라운드 16, 그림자 거의 없음)
- [ ] 카드 머리: 제목 17/500 + 오른쪽 `PillSelect`나 ⋯ 하나
- [ ] 큰 숫자 굵기 500, 단위는 작고 흐리게, 옆에 `Delta`. 숫자에 `.num`
- [ ] 강조 하나: 짙은 버튼(또는 브랜드 버튼) 하나, 차트 강조 하나
- [ ] 짙은 버튼 자리: 체크한 줄의 일괄 동작이면 일괄 띠 오른쪽 끝(Position), 화면 전체 동작이면 머리(Moves). 띠가 사용자를 머리로 다시 올려 보내지 않아요(교육 화면 사례)
- [ ] 목록 화면 툴바 오른쪽이 비지 않아요. 개수 붙은 `Segmented`나 `Tabs`가 있고, 검색이 남는 폭을 채워요(교육 화면 사례)
- [ ] 상태는 점 + 글자 칩. 색만으로 구분하지 않아요
- [ ] 라운드는 허용 목록만 써요: 토큰 6·8·12·16·20·999, 원 50%, PLAYBOOK 6.2 표의 부품 고정값(색 네모 3·4, 체크 5, 작은 상자 7, 트랙 칸·메뉴 줄 9, sm 버튼·⋯·묶음 토글 10, 38px 아이콘 타일 11, 안쪽 상자·칸반 카드 14, 큰 회색 묶음 18, 눈금선 1~2). 새 hex 색, 그라데이션, 큰 그림자, 이모지가 없어요
- [ ] 차트는 `src/ui/charts.tsx`로 그려요. 선이 0 아래로 꺼지지 않고 첫 x 라벨이 잘리지 않아요(실제 사례)
- [ ] 카드 안에 덩그러니 빈 공간이 없어요(흐름 카드 → `fill`). 격자가 휑하지 않아요(도구 2열 → auto-fill 3열)
- [ ] 클릭 뒤 상태(`--flow` 캡처)에서도 같아요. 팁·띠가 사라져도 카드 높이가 맞아요(사라진 자리에 good 한 줄. 예: "30일 뒤에도 모두 최소 이상이에요"). 서랍과 토스트가 겹쳐 보기 흉하지 않아요
- [ ] 반복 패턴(일괄 띠, 묶음 표, 모바일 쌓인 표, 최소 눈금 막대)은 기준 CSS를 복사해 접두사만 바꿨어요(PLAYBOOK 4.0)
- [ ] 카드 크기에 리듬이 있어요(8:4, 7:5, 12)
- [ ] 레퍼런스와 비교한 다른 점 목록을 2번 이상 비웠어요

## 3. 폭
- [ ] 390px: 가로 넘침 없음, 터치 영역 44px
- [ ] 390px 머리 버튼: 2개면 한 줄에 나란히(Moves), 3개 이상이면 짙은 버튼 한 줄 + 나머지 2열(업무사이트 홈). 데스크 작업용 버튼(올리기·내보내기·연결)은 767px 이하에서 숨겨요(3줄 꺾임, 110px 버튼 더미 사례)
- [ ] 390px 표: 열이 많은 표는 Position.css 767px 블록처럼 thead를 숨기고 줄을 카드로 쌓아요. 1줄 체크 + 이름 + 오른쪽 상태 칩 하나, 2줄 메타, 3줄(있으면) 칩 하나 nowrap. 모든 줄에 같은 칩은 숨겨요(줄 130px·칩 홀로 줄바꿈 사례). 열이 적은 표만 `.tablewrap` 가로 스크롤
- [ ] 390px 클릭 뒤: 토스트가 서랍 바닥 버튼·하단 탭을 가리지 않아요(가리면 공통 파일로 보고)
- [ ] 1024px: 상단 검색 글자가 줄바꿈되지 않아요(사례). 표와 카드가 잘리지 않아요
- [ ] 1440px: 칸반 4열, 표의 마지막 열이 다 보여요(4번째 레인 잘림 사례)
- [ ] 높이 960 미만 화면에서 사이드바 아래 진행 카드가 밀려나지 않아요
- [ ] 주 동작(입력 상자, 등록 버튼)이 첫 화면 안에 있어요(채팅 입력 밀림 사례)

## 4. 내용·문구
- [ ] PageHead 설명은 1~2문장이에요. 하는 일과 지키는 원칙 하나를 적어요
- [ ] 첫 줄은 "지금 내가 눌러야 할 것"이에요. AI가 미리 채우고 사람은 한 번 눌러요
- [ ] 매일 쓰는 화면에 필드 5개 이상 폼이 없어요. 자동으로 올 값은 '연동 예정'으로 둬요
- [ ] KPI마다 단위, 비교, '그래서' 한 줄이 있어요. 숫자는 데이터에서 계산하고, 다른 화면과 같아요
- [ ] Delta 자리에는 비교값이나 뜻 있는 상태 칩만 있어요. '예시'는 note나 라벨 뒤 '(예시)'예요(KPI 옆 '예시' 칩 사례)
- [ ] 다른 화면에 없는 사람·이동·건수를 이 화면에서만 지어내지 않았어요. store에 사건이 없으면 그 그룹은 빈 문장이에요(교육 화면의 '검토 중(예시)' 이동 3건 사례)
- [ ] 사람 수를 기준(최소·정원)과 비교할 때는 '12명 · 최소 10', '1명 · 정원 4'로 써요('12/10', '자리 2/4' 사례). 진행(완료/전체)은 '5/8'도 돼요
- [ ] AI 제안에는 근거와 확신도(또는 규칙 이름)가 붙고, 고치는 방법이 있어요
- [ ] 해요체로 짧게 써요. 버튼은 동사예요. 토스트는 과거형 + 다음 일이에요. 영어 라벨, 번역투, 느낌표가 없어요
- [ ] 조사는 `josa()`로 붙여요('대리이에요' 사례)
- [ ] 날짜는 TODAY 기준이에요. '최근' 목록에 미래 날짜가 없어요(사례)
- [ ] 예시 점수·비율이 한쪽에 몰려 있지 않아요(적합도 100 몰림 사례). 모든 상태에 예시가 1건 이상 있어요
- [ ] 빈 상태는 상황 한 줄 + 다음 행동 버튼이에요. 위치 표시(breadcrumb)가 비어 있지 않아요(404 사례)
- [ ] 화면 아래에 "숫자·사람·회사는 모두 예시 데이터예요"가 있어요. 흉내만 내는 버튼은 토스트로 "(예시)"를 알려요
- [ ] 금지어가 없어요: 치료, 진단(질병), 우울 개선, AI 상담사, 위험 직원, 자동 탈락, 불합격(AI 출력), 수정 0, 완벽, 혁신적

## 5. 회사·역할
- [ ] 업무사이트는 `?tenant=tr`와 `?tenant=crata`, 역할 2~3명에서 확인해요. 해당 없는 화면은 `Empty` 안내를 보여요
- [ ] 버튼이 실제로 동작해요. 설정(예: 1단계)이 메뉴와 화면에 진짜로 반영돼요(사례)

## 6. 법·개인정보
- [ ] AI는 추천·제출까지만 해요. 끝내는 버튼(완료, 확정, 합격)은 사람 화면에만 있어요
- [ ] 채용: "AI 추천은 참고예요. 면접 대상·합격은 담당자가 정해요" 문구가 있어요. 추천에서 빠진 사람도 사람이 넣을 수 있어요
- [ ] 지원서에 사진, 키, 체중, 출신 지역, 혼인, 재산, 가족 학력·직업, 나이 필드가 없어요
- [ ] 동의하지 않은 사람의 CRATA 값이 어디에도 없어요('동의 안 함' 칩만). 팀 분포는 5명 이상일 때만 보이고, 숨긴 이유를 적어요
- [ ] ARA 개인 기록이 관리자·인사 화면에 없어요. 회사 집계는 10명 이상일 때만 보여요
- [ ] 개인 데이터 화면에 "누가 볼 수 있고 누가 못 보는지" 한 줄이 있어요
- [ ] L3(학생 식별·상담) 데이터가 예시에도 없어요. L2는 칩과 차단 사례로 보여요
- [ ] 실제 고객 이름은 `identity.ts`에만 있어요. `build:public` 번들에서 0건이에요

## 7. 코드
- [ ] 내 화면 파일만 바꿨어요. 혼자 작업이면 허용된 공통 줄(라우트·메뉴·`PAGE_TITLE`, 새 `src/lib/<page>.ts`·`.test.ts`)만 더했고 보고에 적었어요. 공통 파일 문제는 보고에 적었어요
- [ ] `.sr-only`를 `<th>`·`<td>` 안에 쓰지 않았어요. base.css의 `position:absolute`가 `.tablewrap` 밖으로 빠져나가 390px에서 넘쳐요. 표 머리의 숨김 글은 `aria-label`로 줘요(교육 화면 사례)
- [ ] 파일 첫 줄 주석에 레퍼런스 파일 이름과 가져온 것을 적었어요
- [ ] 선택자는 화면 접두사(`tk-`, `hg-`, `mv-` 등)로 좁혔어요. `span { … }` 같은 넓은 선택자가 없어요(조직도 아바타 사례)
- [ ] `src/ui` 부품을 썼어요. 같은 모양의 버튼·칩·카드를 새로 만들지 않았어요
- [ ] 렌더링에서 `new Date()`를 쓰지 않았어요. 새 npm 패키지를 넣지 않았어요
