# 00. CRATA 인사(HR) 앱 방향 (`apps/hr`)

- 작성: 2026-10-07
- 배경: "HR 쪽만 우선 집중하자"는 결정에 따라 업무사이트(`apps/worksite-next`)와 **따로** 만든 인사 앱입니다. 디자인은 업무사이트에서 정리한 Orbix 스타일(토큰·UI 키트)을 그대로 옮겨 씁니다.
- 회사·사람·지원자는 모두 가상입니다(예시정밀산업, 47명, 지원자 32명).

## 1. 무엇을 하나

| 화면 | 하는 일 |
|---|---|
| 인사이동 (`/moves`) | 대화로 "누구를 어디로"를 적으면 오른쪽 조직도에 바로 반영돼요. 확정 전까지는 깜빡여요. ARA가 잘 맞는지(적합도)와 우려(빈자리·자격·적응)를 같이 말해요. 사람 칩을 끌어다 놓아도 돼요. |
| 구성원 · CRATA (`/people`) | 구성원별 동의 상태와, 동의한 사람만 CRATA 요약·지금 팀 적합도. 팀 분포는 검사한 사람이 5명 이상일 때만 보여요. |
| 채용 공고 (`/hiring`, `/hiring/:id`) | 1차 접수 → 2차 CRATA 검사 → AI 추천 → 면접 → 결과. 회사가 "이런 사람을 뽑고 싶어요"를 적으면 팀 환경과 합쳐 '찾는 사람' 기준을 만들고, 검사 결과로 추천 등급·근거·우려·면접 질문을 줘요. |
| 지원자 화면 (`/apply/:id`, `/test/:id`) | 지원자가 보는 접수 폼과 검사 흐름 예시(회사 메뉴 없이 따로 떠요). |
| 동의 · 보관 (`/policy`) | 아래 3장의 기준을 화면으로 보여 줘요. |

## 2. CRATA 결과를 어떻게 쓰나

검사 구조는 crata.co.kr/tests 공개 설명을 따릅니다.

- **색채검사:** 외면(행동적 태도), 내면(심리적 태도), Comfort Zone(지금 필요한 환경), Challenge Zone(지금 필요하지 않은 환경).
- **행동동기검사:** 시작(무엇이 있어야 움직이나), 지속(무엇이 있어야 오래 가나). 각각 고유와 현재를 나눠요.
- **문제해결방식검사:** 중심·핵심·성장·잠재역량. 공개된 활용처에 면접·직무 배치·팀 구성이 있어요.
- **관계성장방식검사:** 생각을 정리하는 방식(혼자 / 함께), 자신감이 자라는 방식(비슷한 수준 / 다른 수준). 고유와 현재를 나눠요.

**적합도(0~100).** 팀이 주는 환경(`TeamEnv`)과 한 사람의 결과를 7개 항목으로 비교해요.

| 항목 | 비중 |
|---|---|
| 핵심역량 | 25 |
| 중심역량 | 15 |
| 시작 동기 | 15 |
| 지속 동기 | 15 |
| 생각 정리 | 10 |
| 자신감 | 10 |
| 색 환경 | 10 |

- 75 이상은 '잘 맞아요', 55 이상은 '살펴볼 점', 그 아래는 '신중하게'예요.
- 팀 환경은 진단(인터뷰·셰도잉)에서 정하고 팀장이 확인해요.

**이동 조언.** 적합도 말고도 조직 정보로 우려를 찾아요.

- 남는 팀의 최소 인원, 꼭 필요한 기술 보유자 수, 팀장 공석.
- 가는 팀에 필요한 교육·자격.
- 입사·최근 이동 시기, 교대 근무 가능 여부.
- 큰 우려가 있으면 판정을 한 단계 낮춰요. 더 맞는 팀이 있으면 함께 알려 줘요.

**예시인 것.** 색 이름, 동기·역량 항목 이름, 팀 환경 값, 가중치는 화면을 만들려고 정한 예시예요. 실제 CRATA 결과지 항목과 가중치로 바꿔야 해요(`src/lib/model.ts`, `src/lib/fit.ts`).

**지금은 규칙 기반이에요.** 대화 해석(`parse.ts`)과 조언(`fit.ts`)은 AI 없이 돌아가고 단위 테스트 14개가 있어요. 실제 서비스에서는 이 결과를 근거로 ARA(LLM)가 문장을 다듬게 하면 돼요. 근거 없는 판단을 지어내지 않게 하려는 구조예요.

## 3. 꼭 지킬 기준

### 3.1 직원 CRATA 결과
- 기본은 **본인만**이에요. 회사는 검사한 사람이 5명 이상인 팀의 분포만 봐요.
- **배치 참고에 따로 동의한 사람만** 개인 결과를 인사이동 추천에 써요. 동의는 언제든 철회할 수 있고, 응하지 않아도 불이익이 없어요.
- **ARA 복지 공간의 대화·마음 체크인은 인사에 쓰지 않아요.** 두 데이터는 따로 저장해요.
- ⚠️ **기존 계약 조항과 충돌해요.** [04 데이터 거버넌스](../research/04_data-governance.md) 8.2절과 [03 Company DNA](../research/03_company-dna-playbook.md) L8에는 "결과는 인사평가·배치·보상에 쓰지 않는다"는 조항이 있어요. 이 조항은 진단 컨설팅용이에요. HR 제품을 팔려면 다음을 새로 정해야 해요.
  - (a) 배치 참고 활용은 별도 동의(opt-in), 철회 가능, 거부 시 불이익 없음.
  - (b) 평가·보상에는 계속 쓰지 않음.
  - (c) 고용관계에서는 동의의 자발성이 약하다고 보는 시각이 있어요. 동의율만 보지 말고, 동의하지 않은 사람도 같은 절차로 배치되는지 점검해야 해요.
- 상시 30인 이상 사업장이면 새 인사 시스템 도입이 노사협의회 협의 사항일 수 있어요(근로자참여법 제20조, 04 문서 8.3절과 같은 판단). 도입 전에 확인하세요.

### 3.2 채용
- **AI는 추천과 근거만 내요. 면접 대상·합격·불합격은 담당자가 정해요.** 자동 탈락은 없어요. 추천에서 빠진 사람도 담당자가 면접에 넣을 수 있어요.
- 인공지능 기본법(2026-01-22 시행)은 채용처럼 사람의 권리·의무에 큰 영향을 주는 판단에 쓰는 AI를 고영향 AI로 봐요. 우리가 할 일은 이렇게 잡았어요(조문 번호와 세부 의무는 시행령·고시로 확인 필요).
  - 지원자에게 AI가 쓰인다는 사실을 미리 알려요.
  - 추천 근거를 설명할 수 있게 해 둬요.
  - 사람이 관리·감독해요.
  - 기록을 보관해요.
- 개인정보보호법 제37조의2(자동화된 결정)는 완전히 자동화된 결정에 거부·설명 요구권을 줘요. 사람이 최종 결정하는 구조라도 지원자가 요청하면 추천 근거를 설명해요.
- 채용절차법 제4조의3은 지원서에서 다음을 받지 못하게 해요. 이 법은 상시 30명 이상 사업장에 적용돼요(제3조).
  - 용모·키·체중 같은 신체 조건.
  - 출신 지역, 혼인 여부, 재산.
  - 직계 존비속·형제자매의 학력·직업·재산.
- 연령차별금지법 때문에 나이도 받지 않아요.
- 채용절차법 제11조에 따라 채용서류 반환 청구 기간은 14~180일 중 회사가 정해요. 그 기간이 지나면 서류를 파기해요. 예시 화면은 180일로 적었어요.
- 검사 결과는 그 채용 판단에만 써요. 인재풀 보관은 따로 선택 동의를 받아요.

## 4. 다음 할 일
1. CRATA 실제 결과지 항목·코드와 연결하고, 검사 화면 연동 방식(링크·결과 회수)을 정해요.
2. 팀 환경 값을 첫 고객 진단에서 뽑고 팀장 확인 절차를 만들어요.
3. 가중치를 검증해요. 이동·채용 뒤 6~12개월 적응·이직 데이터와 비교하되, 집단별(성별·연령) 차이가 생기지 않는지도 점검해요.
4. 계약서·동의서 문안을 위 3장 기준으로 다시 써요(법률 검토).
5. ARA(LLM) 문장 다듬기. 규칙 결과만 근거로 쓰게 프롬프트를 고정하고, 근거 없는 문장은 막아요.
6. 인사 기록(발령일·발령장)·급여 시스템 연동은 '만들지 않고 연결'해요.
